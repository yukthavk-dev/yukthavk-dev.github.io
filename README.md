# Yuktha Venkatesan — Portfolio

A responsive, static portfolio built with HTML, CSS, and a small amount of JavaScript. Open `index.html` in a browser to view it.

## Update the content

- Edit the categorized skill tags in the `#skills` section of `index.html` as your toolkit grows.
- Add or update projects by copying one of the `<article class="project-card">` blocks in the `#projects` section.
- Add project demo or repository links only when those URLs are ready.
- The GitHub and LinkedIn profile links appear in the About, Contact, and footer sections.
- Add an email address to the Contact section whenever you want to publish one.

`styles.css` contains the layout, colors, responsive breakpoints, and motion preferences. `script.js` handles the small-screen menu, reveal effects, and footer year.
